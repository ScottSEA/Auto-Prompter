# Issue tracker: GitHub

Issues and PRDs live in GitHub Issues for `ScottSEA/Auto-Prompter`. Use GitHub issue operations;
infer the repository from the current clone.

## Conventions

- Create, read, list, label, comment on, and close GitHub issues.
- Fetch issue comments and labels when gathering requirements.
- Any issue or PR comment posted on Scott Baker's behalf must end inline with
  `_AI-generated OBO Scott Baker_`.
- PRs as a request surface: no.
- A bare `#42` may be an issue or PR; resolve its type before acting.

## Skill meanings

- "Publish to the issue tracker" means create a GitHub issue.
- "Fetch the relevant ticket" means read the GitHub issue with comments and labels.
- Wayfinder maps use a `wayfinder:map` issue, linked child issues, native dependencies where
  available, and `wayfinder:<type>` labels.
